# Evidencias de la Aplicación Web (Fase 3)

## Componentes Completados
- Integración completa con API de .NET mediante `ApiClient` (RestClient).
- Flujo de autenticación e interceptor de roles con JWT.
- Funcionalidades del Cliente (Catálogo, Perfil, Direcciones, Pedidos).
- Funcionalidades del Administrador (CRUD Productos, Categorías, Drops, Usuarios, Pedidos, Auditoría, Asignar Repartidor).
- Funcionalidades del Repartidor (Pedidos disponibles, Tomar pedido, En camino, Entrega exitosa/fallida).
- Plantillas completadas con Thymeleaf y layout dinámico por rol.
- Estilos aplicados (dark theme - `style.css`).

La aplicación está testeada con compilación exitosa (`mvn clean package`) y está lista para su despliegue y presentación.
